CPU Scheduling Concepts & Simulator

Definitions

  • Arrival Time (AT): When a process arrives in the ready queue.
  • Burst Time (BT): Total CPU time required by the process.
  • Priority: Importance level. (Here: Lower number = Higher priority).
  • Ready Queue: The list of processes waiting in memory to be executed.

Core Formulas

  • Turnaround Time (TAT) =
    Finish Time - Arrival Time
  • Waiting Time (WT) =
    TAT - Burst Time
  • Response Time (RT) =
    First Start Time - Arrival Time

Algorithms

  • FCFS: Executes strictly in order of arrival. Simple but prone to the "Convoy Effect".
  • SJF (Non-Preemptive): Executes the shortest job available. Once started, runs to completion.
  • SRTF (Preemptive SJF): Always runs the job with the shortest remaining time. Preempts running jobs.
  • Priority: Runs jobs based on priority value.
  • Round Robin: Gives each job a fixed time slot (Quantum). Cycles through the queue.
