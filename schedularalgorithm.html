Theory & Concept Guide

What is CPU Scheduling?

It is the process of determining which task in the Ready Queue is allocated the CPU for execution. Its primary goal is to maximize CPU utilization and minimize process waiting times.

Why is it needed?

Without it, a single process could monopolize the CPU, causing the system to freeze. Proper scheduling enables multiprogramming, keeping the CPU continuously busy even when some tasks wait for I/O.

Preemptive vs. Non-Preemptive

Non-Preemptive: A process holds the CPU until it finishes its burst (e.g., FCFS, SJF, Non-Preemptive Priority).
Preemptive: The OS can forcefully interrupt a running process to run a more urgent one (e.g., Round Robin, SRTF, Preemptive Priority).

Scheduling Metrics & Formulas (Standard Units: Milliseconds / ms)

AT
Arrival Time
The time a process arrives in the ready queue.
BT
Burst Time
Total CPU execution time required by the process.
CT
Completion Time
The exact time a process finishes execution.
TAT
Turnaround Time
Formula: CT - AT
Total time spent in the system.
WT
Waiting Time
Formula: TAT - BT
Total time spent waiting in the ready queue.
RT
Response Time
First Start - AT
Time from arrival to first CPU allocation.
